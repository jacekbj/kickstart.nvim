# Cheatsheet

## LSP
- `gra`        code action (e.g. auto-import the symbol under cursor)
- `grn`        rename symbol
- `grr`        references

## Completion (insert mode)
- `<C-space>`  open the completion menu for the word before the cursor
- `<C-y>`      accept item (also adds its import)

## Comments
- `gcc`        toggle comment on line
- `gc`         toggle comment on visual selection
- `gcip`       toggle comment on paragraph

## Misc
- `<leader>sk` search all keymaps
- `<leader>gm` commit message for current line
